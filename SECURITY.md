# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security-related issues, please report them responsibly:
- Email Anton Barinov at `55404783+Anton-Barinov@users.noreply.github.com` or create a private GitHub Security Advisory.
- Please do not disclose vulnerabilities publicly until a fix has been released.

We take security vulnerabilities seriously and will promptly investigate and publish a patch.
